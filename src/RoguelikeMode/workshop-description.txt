A pure roguelike mode. No ship or campaign, just five levels of sharply increasing difficulty as you start with nothing and scavenge your way to the Golden Keycard, your only way out of this pit of hell.

[b]EXPERIMENTAL v0.4[/b] - this is under active development and so there may be some bugs. It never touches campaign slots, so it should be safe to use. Always back up saves before using new mods!

[h2]The Dive[/h2]
Find the new game mode button on the main menu. Clicking this takes you to [b]The Dive - Roguelike Mode[/b], where you can choose between:
[list]
[*][b]Daily Dive[/b] - a seed-based run which is the same for everyone on the same day. A countdown on the Dive screen shows how long until the next daily
[*][b]Random Dive[/b] - a completely random run
[/list]

Then choose difficulty, which loosely maps to the game's difficulties:
[list]
[*][b]Easy[/b] - get a significant supply crate near the entrance to each elevator
[*][b]Normal[/b] - get a small supply crate near the entrance to each elevator
[*][b]Hard[/b] - nope
[/list]

Then choose one of three randomly generated characters. For a Daily Dive, these are the same for everyone. They roll with random stats [i]and[/i] classes.

[h2]Objective[/h2]
Find the [b]Golden Keycard[/b] on the bottom level (level 5). This is the only way to win the run and provides a significant bonus to your run score!

[h2]Barter Terminal[/h2]
Every floor has a glowing terminal near the entrance. Load it with anything you don't need, hit [b]TRADE-IN[/b], and it pays out random gear worth 85% of the value, scaled to your current depth. One use per floor, and any leftover value carries to the next terminal as credit. On a Daily Dive the trades are deterministic, so the same offering gets everyone the same result.

[h2]Save and Exit[/h2]
You can now suspend a run from the ESC menu and resume it later, exactly where you left off. Daily runs expire when the daily resets, so finish your dive before the clock runs out!

[h2]Scoring[/h2]
The score for a run is determined by a number of factors, not exhaustively:
[list]
[*]Level reached
[*]Kills
[*]Victory bonus
[*]Damage taken
[*]Difficulty multiplier
[/list]
Using console commands during a run disables scoring for that run. You can still finish it, but the dive log will never know.

[h2]Dive Log[/h2]
Runs are kept locally in your dive log. There are no save slots used, but run history is stored in mod-specific [i]roguelike_*.dat[/i] files alongside your save files.

[h2]Online Daily Ladder (NEW)[/h2]
The Dive screen now has a [b]LADDER[/b] tab showing a global daily leaderboard for each difficulty. Ranked runs are Daily Dives only - the random mode stays offline.

Submitting your runs is [b]opt-in and off by default[/b]. Flip [b]SUBMIT MY DIVES[/b] on the ladder tab (or use the [i]rogue_ladder[/i] console command) to join in. When enabled, a finished daily dive sends your Steam name, Steam ID and run stats to the ladder server; your Steam ID is used once to keep one best score per player per day and is stored only as an anonymous hash, never raw. Reading the board sends nothing about you. Turn it off any time and nothing further is sent.

Other mods are welcome on the ladder - runs made with other mods active simply carry a [b]*[/b] on the board so everyone can see it. Console cheats disable scoring and ladder submission for that run entirely.

[h2]Additional Mechanics/Changes[/h2]
[list]
[*][b]Updating class[/b] - if you find an item which unlocks a new class/perk, you can now apply that during the run. This makes these items much more useful and interesting to find!
[*][b]Field surgery[/b] - implants and prosthetics can be installed straight from your inventory during a run. The usual socket and compatibility rules apply
[*][b]Loot tuning[/b] - weapon and armor cases no longer appear in floor loot on Normal and Hard, so your gear upgrades have to be earned. Easy keeps them
[*][b]The keycard shines[/b] - you'll know it when you see it
[/list]
